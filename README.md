# SOCIAL-MEDIA-ENGAGEMENT-ANALYSIS-USING-PYTHON

## Project 
This project analyses social media data to understand user activity and post engagement.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Work Done
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Data exploration and statistical analysis
- Data visualization
- Engagement analysis by post type, category, country and device

## Dataset
Social media engagement dataset containing 5,000 records.

## Outcome
The project helped me understand social media engagement patterns through Python and data visualization.
